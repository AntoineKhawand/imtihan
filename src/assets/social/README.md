The Fraunces Medium TTF is a local Google Fonts subset for the social-image headline, “Vos examens, simplement.” It is bundled so sharing does not depend on a remote font request. The source is Google Fonts (fonts.googleapis.com, Fraunces weight 500); the upstream SIL Open Font License is included in OFL-Fraunces.txt. If the headline changes, regenerate its character subset. Geist fonts come from the existing geist dependency; the logo is the existing public/Imtihan-logo.png used on the website.
